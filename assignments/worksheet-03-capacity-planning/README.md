## Q2: Felt-tip pens

Demand 30,000/month · FC $25,000/month · v = $0.37

- **(a)** At $1: Q<sub>BEP</sub> = 25,000 ÷ 0.63 = 39,682.5 → **39,683 pens**
- **(b)** $15,000 profit at 30,000 pens: 30,000R = 15,000 + 11,100 + 25,000 = 51,100 → R = 1.7033 → **$1.71**
- The key rounds the price **up**, which is right: at $1.70 the profit would be only $14,900.

## Q3: Pottery plant

FC $9,200/month · v = $0.70 · R = $0.90 (contribution $0.20)

- **(a)** Q<sub>BEP</sub> = 9,200 ÷ 0.20 = **46,000 units/month**
- **(b)** 61,000 units → 12,200 − 9,200 = **$3,000** · 87,000 units → 17,400 − 9,200 = **$8,200**
- **(c)** $16,000 profit → (16,000 + 9,200) ÷ 0.20 = **126,000 units**

## Q4: Bottleneck machine

FC Tk 42,000 · v = Tk 15 · R = Tk 22

- **(a)** C(q) = 42,000 + 15q · R(q) = 22q · **P(q) = 7q − 42,000**
- **(b)** 7q = 42,000 → **6,000 units**
- **(c)** P(5,000) = 35,000 − 42,000 = **−Tk 7,000** (a loss)
- **(d)** 7q − 42,000 = 7,000 → **7,000 units**
- **(e)** 4,000 = 1,000x − 57,000 → **x = Tk 61**
