# Engineering-Management

Coursework for **Engineering Management**, Section J (AIUB), Fall 2026-27.

- **Faculty:** Arif Khan (arif.khan@aiub.edu). Consultation 13:00–14:30, Mon/Wed
- **Textbook:** William J. Stevenson, *Operations Management*, 12th ed.
- **Marks:** attendance 13 · engagement 2 · worksheets 5 · quiz (best of 2) 10 · case study 10 · group project 10 · exam 50, plus Kahoot bonus. Midterm 40% / final 60%.
